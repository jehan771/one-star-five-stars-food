An alien tourist's one-star review of planet Earth — that still slips in a
real compliment about the food. One sentence, at most 200 characters, written
by `main.ts` to `/output/entry.txt` for the make.fun competition
[One Star, Five Stars for the Food](https://make.fun/bounty/u-po-pu-one-star-five-stars-for-the-food-f9166ee7).

## The sentence

> One star: Earth is 70% water and still charges me for a bottle of it, but the bakso broth was so good I drank it with all four hands.

## Run

```sh
node entry/main.ts   # writes /output/entry.txt, asserts the 1–200 char / one-sentence gate first
```

The program is deterministic: every run writes byte-identical output.
